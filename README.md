# AnimeVault Mobile

The mobile application side of the AnimeVault project, built to bring the AnimeVault experience to Android/mobile devices.

## 🎯 Goals

- Mobile-first anime discovery
- User accounts and personalized content
- Anime information and browsing
- Playback-oriented mobile UX
- Fast, responsive navigation

## 🛠️ Stack

- React Native
- TypeScript
- Native mobile tooling

## 🚀 Development

Follow the native project configuration and package scripts included in the repository. Keep API keys and environment-specific configuration out of source control.

## 🚧 Status

Active development / work in progress.
